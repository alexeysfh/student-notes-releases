# Student Notes downloads

Official desktop download packages for [Student Notes](https://studentnotes.page/download), published by Omniq UG (haftungsbeschränkt).

## Current distribution

Version 1.0.0-preview.1 is an early test distribution, not a stable public launch.

- macOS: Apple Silicon, macOS 12 or later. Developer ID signing and Apple notarization are still pending.
- Windows: x64 portable package. Unzip the entire folder and start StudentNotes.exe. Windows runtime acceptance and publisher signing are still pending.
- A Student Notes account is required. Plus purchases are not released in this preview.

The application source, private credentials and user data are not published in this repository.
